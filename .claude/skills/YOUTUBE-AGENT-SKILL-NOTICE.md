# Source of the yt-* skills

The `yt-*` skill folders in this directory are copied unmodified from
https://github.com/Jakeschincariol/youtube-agent-skill (commit a2feb21), MIT license.
See `YOUTUBE-AGENT-SKILL-LICENSE`.

`.claude/youtube/voice.md` is the voice-profile template from the same pack. The skills look for
`~/.claude/youtube/voice.md`; in a cloud session read this file from the repository instead.
