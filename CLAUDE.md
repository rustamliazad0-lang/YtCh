# YtCh: карта действий

Репозиторий канала WorstCase (@reality_glitch1_1, YouTube Shorts «Что если...»). Кода нет: только скилы, заметки и голос канала. Пользователь пишет по-русски, отвечать по-русски.

## Правила экономии

- Не исследовать репозиторий заново. Вся структура ниже. `find`/`ls` только если файла нет там, где сказано.
- Простой вопрос: ответить сразу, без инструментов. Один файл нужен: прочитать его, не соседние.
- Задача совпала со строкой таблицы: сразу вызвать этот скил, без плана и без уточнений, если вход уже есть.
- Не пересказывать, что сделано, и не предлагать «что ещё». Ответ, потом одна строка о следующем шаге, если он нужен.
- Пользователь просит короче или «меньше токенов»: скил `caveman`.
- Сабагентов не запускать без просьбы.

## Задача → действие

| Просят | Делать |
|---|---|
| сценарий, хук, «что сказать в начале» | `yt-script` |
| заголовок, обложка, переименовать ролик | `yt-package` (запрет «Часть N»/«Серия N», см. notes) |
| описание, теги, SEO | `yt-seo` |
| главы, таймкоды | `yt-chapters` |
| нарезать на Shorts | `yt-shorts` |
| вырезать паузы, сократить запись | `yt-edit` |
| почему уходят зрители, удержание, CSV удержания | `yt-retention` |
| ответить на комментарии | `yt-comment` |
| план на неделю/месяц | `yt-plan` |
| что работает в нише, конкуренты | `yt-viral` |
| аудит канала | `yt-audit`, но сначала прочитать `notes/youtube-channel-review.md`, не повторять уже сделанное |
| сделать текст «человечным», убрать следы ИИ | `humanizer` (работает здесь; к русскому тексту применять те же паттерны, их русские аналоги: «не просто X, а Y», «давайте разберёмся», тире везде, тройки) |
| то же, но локальной моделью на своём компьютере | `humanizer-local` (в облаке не работает) |
| короче, без воды | `caveman` |

Текст для зрителя (сценарий, описание, ответ в комментариях) после yt-скила прогонять через `humanizer` в embedded-режиме: вернуть только итоговый текст.

## Карта памяти

| Что | Где |
|---|---|
| Цифры канала, что сработало, план улучшений (2026-11-24) | `notes/youtube-channel-review.md` |
| Голос канала (шаблон, пока не заполнен) | `.claude/youtube/voice.md`; yt-скилы ищут `~/.claude/youtube/voice.md` |
| Сценарии, хуки, заголовки серии «Бункер» (A, B, C) | `series/bunker/scripts.md` |
| Раскадровки (PNG) и генератор кадров | `series/bunker/storyboard/`, `series/bunker/build_storyboard.py` |
| **Стиль всех роликов (утверждён)**, читать перед любым сценарием | `series/STYLE.md` |
| Ролики D и E (еда на 9, радиация и вода), раскадровки | `series/bunker/scripts.md`, `storyboard/bunker-D.png`, `bunker-E.png` |
| Черновики ответов на комментарии под «Бункером» | `series/bunker/comment-replies.md` |
| Новые заголовки для слабых роликов | `notes/retitles-2026-11-25.md` |
| Идеи следующих роликов | `series/ideas-2026-11-25.md` |
| Скилы | `.claude/skills/<имя>/SKILL.md` |
| ZIP-архивы yt-скилов для загрузки в claude.ai | `dist/` |
| Лицензии скилов | `.claude/skills/YOUTUBE-AGENT-SKILL-LICENSE`, `humanizer/LICENSE`, `caveman/LICENSE` |
| Облачная память Claude Code | инструменты `mcp__memory__*`; факты о пользователе и решения, которых нет в репозитории |

Куда записывать новое:
- Новый разбор, аналитика, решение по каналу: файл в `notes/` с датой в имени или в заголовке, плюс строка в таблицу выше.
- Изменились цифры канала: дописать в `notes/youtube-channel-review.md` новый блок с датой, старые не стирать.
- Предпочтения пользователя о работе Claude: облачная память, не этот файл.

## Известные факты (не перепроверять)

- Формула хита: «Что если...» + угроза/выживание + конкретный срок. Лучший ролик «Бункер за 365 дней», 41,7x.
- 93,5% просмотров из ленты Shorts: обложка почти не влияет, важны первые 2-3 секунды и заголовок.
- Канон «Бункера» (семья из 5, гараж у деда, скважина, бак с соляркой, 11 000 порций, стук в люк на 365-й день) лежит в `series/bunker/scripts.md`. Перед сценарием по серии читать его, оригинал уже расшифрован.
- `hookscore.py` работает по английским словам, на русском его не использовать; `title.py` на русском работает.
- vidIQ не отдаёт CTR и показы; TikTok не подключён.
